# 🎙️ SPA 영어 말하기 연습

SPA(Speaking Proficiency Assessment) 진급 시험을 대비하는 영어 인터뷰 연습 웹앱입니다.

👉 **https://cheesebyte99.github.io/spa-practice/**

휴대폰 크롬에서 열고 메뉴 → **홈 화면에 추가**를 누르면 앱처럼 쓸 수 있어요.

## 할 수 있는 것

- 🎯 **실전 모의시험**: 시험관 목소리로 질문 13개(난이도 1 → 5 + 추가 질문)를 들려주고, 내 답변을 녹음·받아쓰기
- 💬 **질문 연습**: 자기소개·업무·경험·의견·롤플레이·산업 이슈 등 46개 질문, 답변 요령, 모범 답변, 핵심 표현
- 📊 **자동 피드백**: 답변 길이, 말하기 속도, 연결어 사용, 핵심 표현 사용 여부
- ✍️ **스스로 채점**: 유창성·내용 구성·어휘·문법·발음 1~5점
- 📒 **회화 단어장**: 회의·업무·자동차 산업·의견 표현 등 150여 개 표현, 카드 외우기
- 🗂️ **기록**: 녹음과 결과는 이 휴대폰에만 저장
